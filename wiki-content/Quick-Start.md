# Quick Start

## Reading the docs locally

```bash
pip install -r requirements.txt
mkdocs serve
```

Open http://127.0.0.1:8000.

## New project — sane plugin defaults

Enable these in `Edit → Plugins`, restart, and you have a modern UE 5.7 base:

- Nanite, Lumen, Virtual Shadow Maps
- Modeling Tools Editor Mode
- Geometry Script
- PCG Framework, PCG Examples
- Common UI, Enhanced Input
- Python Editor Scripting
- Editor Utility Widgets
- MetaSounds
- Sequencer, Niagara

Optional, per-project: Pixel Streaming, DLSS / Streamline, Composure, GAS.
