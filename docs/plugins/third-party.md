## Vetting checklist

Before depending on a Marketplace plugin:

1. **License** — verify use case (commercial / royalty / per-seat).
2. **Source access** — closed-source plugins create upgrade lock-in.
3. **UE version support** — many lag major UE releases.
4. **Platform support** — verify Windows / Mac / Linux / consoles.
5. **Maintenance signal** — release cadence in the past year.
6. **Forum activity** — does the author respond?
