# Plugins

The plugin ecosystem in UE 5.7 has three sources:

| Source | Examples |
| --- | --- |
| **Built-in** | Ships with the engine; toggle in Plugins window |
| **Marketplace / Fab** | Downloaded into `<Project>/Plugins/` or `<Engine>/Plugins/Marketplace/` |
| **Community / GitHub** | Cloned into `<Project>/Plugins/` and compiled |
